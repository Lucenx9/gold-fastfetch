## Codebase Patterns
- scripts/lib.sh is the shared library — all scripts should `source` it for logging and checks
- Use `printf` instead of `echo -e` for colored output
- All shell scripts need `#!/usr/bin/env bash` and `set -euo pipefail`
- Run `shellcheck` on all `.sh` files before committing
- Git repo local config: user=Lucenx9, email=Lucenx9@users.noreply.github.com
- Use `${var,,}` for lowercase and `${var^}` for capitalize-first instead of piping to `sed`
- Config templates use `{{PLACEHOLDER}}` syntax (double curly braces) — replaced by `sed` at install time
- Config templates are valid JSON — can be validated with `python3 -c "import json; json.load(open('file'))"`
- Use `[[ "${BASH_SOURCE[0]}" == "$0" ]]` guard to make scripts sourceable for testing without running main logic
- bats installed at `~/.local/bin/bats` — add to PATH before running: `export PATH="$HOME/.local/bin:$PATH"`
- `EUID` is readonly in bash — to test root-check logic, replicate the condition inline in a wrapper function
- shellcheck exits 1 on SC1091 (info level) — use `-S warning` to only fail on actual warnings/errors
